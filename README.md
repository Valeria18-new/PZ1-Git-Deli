Временное изменение для примера git stash.
## Практическая работа № 2. CI/CD

В рамках работы создано простое приложение-калькулятор на языке JavaScript.

Версия приложения: 1.0.0.

### Реализованные функции

- сложение двух чисел;
- вычитание двух чисел.

### Автоматическое тестирование

Для автоматической проверки используется GitHub Actions. При отправке изменений в ветки main, development и release запускается файл test.js. Если все вычисления выполнены правильно, рабочий процесс завершается успешно.
